Connect a free Supabase project (real Postgres database) so every device — any phone, anywhere, no Claude needed — reads and writes the same central data.

  1. Go to supabase.com, sign up free, and create a new project (pick any name/password/region).
  2. Once it's ready, open SQL Editor → New query, paste the setup script below, and click Run.
  3. Go to Project Settings → API. Copy the Project URL and the anon public key.
  4. Paste both below and click Connect. Share the same two values with your team.
